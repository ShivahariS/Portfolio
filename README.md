# Shivahari S. — React Portfolio

Dark-purple editorial portfolio inspired by the supplied reference PDF. Built with React, Vite, Framer Motion, and Lucide icons.

## Run in IntelliJ IDEA
1. Extract the ZIP and open the folder containing `package.json`.
2. Open **View → Tool Windows → Terminal**.
3. Check Node.js: `node -v` and `npm -v`.
4. Run `npm install`, then `npm run dev`.
5. Open the local URL Vite prints, usually `http://localhost:5173`.
6. Keep the terminal running for hot reload.

## Personalize before publishing
- Add your photo as `public/profile.jpg`.
- Replace `your.email@example.com` in `src/App.jsx`.
- Replace GitHub and LinkedIn placeholder URLs.
- Replace education placeholders with your actual degree, institution, and graduation year.
- Add a resume link and `public/resume.pdf` when ready.
- Project statuses are intentionally honest: Expense Tracker is **In progress**; Job Application Tracker is **Planned**.

## Build and deploy
`npm run build` creates `dist/`. Import this repository into Netlify or Vercel, use build command `npm run build`, output directory `dist`.
